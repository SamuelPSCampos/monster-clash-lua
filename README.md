# 🐉 Monster Clash

**Monster Clash** is a terminal-based, turn-based battle game written in **Lua (5.4.2)**, developed in **Visual Studio Code** using the **Lua Language Server** extension (by sumneko).
This project was built as a **learning and code showcase**, focusing on clean architecture, modular design, and game logic without external libraries or engines.

---

## 🎮 Overview

- Runs entirely in the terminal
- Sequential combat against 4 monsters
- Turn-based battle system with basic enemy AI
- ASCII-based UI and stat visualization

![Game Menu](https://imgur.com/XTOdm08.png)

---

## 🧠 Technical Focus

- Pure Lua (no frameworks or engines)
- Modular architecture with clear responsibility separation
- Scalable stat system based on a shared base attribute
- Defensive programming and runtime validations
- Rendering logic fully decoupled from game logic
- Deep copy usage to avoid shared state mutation

![Game Protagonist](https://imgur.com/MKo6GN8.png)

## ▶️ Running the Game

### Requirements
- **Lua 5.4.2**

### Run
```bash
lua main.lua
```
